What DIFFERS means depends on which build you compared with.

`cargo near build reproducible-wasm` IS byte-stable: it builds the
committed commit inside a digest-pinned container, so a mismatch there
means the deployed code is not this commit. That is the comparison a third
party can make, and the one the deployed contracts were built for.

`npm run build:contracts` uses non-reproducible-wasm and your local
rustc, so it legitimately produces different bytes from the same source.
A DIFFERS against THAT build tells you nothing on its own.

To reproduce the deployed bytes yourself:
  cargo near build reproducible-wasm --manifest-path contracts/<name>/Cargo.toml

If it still differs, the remedy is:  NEAR_REDEPLOY=<name> npm run deploy
